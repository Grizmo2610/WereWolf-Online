# 07 - UI & Frontend

## 1. Stack

| Thứ | Dùng cho |
|---|---|
| React + Vite | Component-based UI, client-side routing |
| TailwindCSS (v4) | Layout, spacing, responsive — kết hợp với các class dùng chung ở `index.css` cho phần "look" khó diễn đạt bằng utility (glass blur, gradient text, v.v.) |
| Framer Motion | Animation (phase transition, reveal role, người chết) |
| Zustand | Global state (game state, WebSocket events) |
| React Query | Fetch API (auth, room config) — không dùng cho WebSocket |

## 2. Theme — màu sắc, font, background

Palette định nghĩa một lần trong `frontend/src/config/theme.js` (bản ghi chép JS, để tham chiếu/document), nguồn sự thật thực sự là các CSS variable khai báo trong `:root` ở `index.css`. Không hardcode màu trong component — chỉ dùng CSS variable.

```css
:root {
  --bg-from:      #1b2735;              /* nền radial-gradient — điểm bắt đầu */
  --bg-to:        #090a0f;              /* nền radial-gradient — điểm kết thúc */
  --card-bg:      rgba(17, 20, 30, 0.75); /* nền glass card */
  --card-border:  rgba(255, 255, 255, 0.08);
  --text:         #e2e8f0;              /* chữ thường */
  --text-strong:  #f1f5f9;              /* chữ đậm, tiêu đề, tên người chơi */
  --text-muted:   #94a3b8;              /* label, meta text */
  --text-faint:   #64748b;              /* footer text */
  --text-faintest:#475569;              /* placeholder, hint */
  --accent-red:   #e43f3f;              /* gradient nút chính, viền "tôi", nguy hiểm */
  --accent-orange:#ff7b00;              /* gradient nút chính, link, gradient chữ tiêu đề */
  --input-bg:     rgba(255, 255, 255, 0.05);
  --input-border: rgba(255, 255, 255, 0.1);
  --success:      #22c55e;              /* trạng thái "Sẵn sàng" */
  --warning:      #f59e0b;              /* trạng thái "Chờ..." */
  --danger:       #f87171;              /* nút Thoát phòng, thông báo lỗi */
}
```

**Class dùng chung** (khai báo trong `index.css`, không lặp lại inline style ở component):

| Class | Dùng cho |
|---|---|
| `.glass-card` | Card nền mờ (`backdrop-filter: blur(16px)`), viền mảnh, bo góc 20px, shadow sâu — dùng cho mọi card trong toàn app |
| `.gradient-text` | Chữ gradient cam→đỏ (`background-clip: text`) — tiêu đề card, tên phe trong RoleCard |
| `.logo-circle` | Vòng tròn nền gradient tối, chứa emoji 🐺 — logo ở Login/Register |
| `.avatar-circle` | Vòng tròn avatar nhỏ (Lobby, Room, seat trong Game) |
| `.form-label` / `.form-input` / `.form-hint` / `.form-error` | Input, label, hint, thông báo lỗi — dùng xuyên suốt các form |
| `.btn` + `.btn-primary` / `.btn-accent` / `.btn-danger-outline` | 3 biến thể nút: gradient đỏ→cam (hành động chính), viền cam nhạt (hành động phụ), viền đỏ nhạt (hành động nguy hiểm/thoát) |
| `.status-pill` (`.ready` / `.waiting`) + `.status-dot` | Badge trạng thái sẵn sàng/chờ trong phòng chờ, có dot nhấp nháy khi đang chờ |
| `.toggle-row` | Hàng checkbox + label (dùng cho "Lộ role khi chết") |
| `.moon-glow` | Quầng sáng đỏ-cam mờ góc trên-phải, chỉ dùng ở Login/Register |
| `.mention-pulse` | Hiệu ứng viền nhấp nháy cam khi bubble chat nhắc tới mình |

**Mapping cụ thể:**
- Người chết trên seat circle: `opacity-40 grayscale` (áp qua Framer Motion `animate`, xem mục 7).
- Seat của chính mình: viền `--accent-red` dày 3px.
- Seat đang chọn (đêm/vote): viền `--accent-orange`, có glow.
- Tên đồng đội Sói (chỉ Sói thấy): nền gradient đỏ, chữ trắng.
- Banner chết/trục xuất: nền `rgba(248,113,113,0.15)`, chữ `#fca5a5`.
- Banner sự kiện thường/đổi phase: nền `rgba(255,123,0,0.1)`, chữ `--accent-orange`.
- Banner an toàn ("không ai chết"): nền `rgba(34,197,94,0.1)`, chữ `--success`.
- Phase đêm: overlay phủ toàn màn hình bằng gradient tối hơn cả nền thường (`#0d1420` → `#030407`), opacity 70%.
- Chat bubble: nền `rgba(255,255,255,0.05)`, viền mảnh; bubble của mình căn phải.
- Mention highlight: viền `--accent-orange` 2px + animation pulse.

**Font:** `'Segoe UI', Tahoma, Geneva, Verdana, sans-serif` — set một lần trên `body` qua biến `--font-app`. (Không còn dùng Times New Roman như bản thiết kế đầu.)

**Background:** Không dùng ảnh. Nền là `radial-gradient(ellipse at bottom, var(--bg-from) 0%, var(--bg-to) 100%)` cố định trên `body`, cộng thêm lớp `body::before` vẽ các đốm sao nhỏ lặp lại (`radial-gradient` nhiều điểm) và animate nhấp nháy nhẹ (`@keyframes twinkle`, 4s, opacity 0.2↔0.35). Toàn bộ nội dung app nằm trong `#root { z-index: 1 }` để nổi trên lớp sao.

## 3. Layout & Screens

### Login / Register
Form `.glass-card` căn giữa màn hình, có `.moon-glow` phía sau, logo emoji 🐺 trong `.logo-circle`, tiêu đề dùng `.gradient-text`. Sau đăng nhập → redirect `/lobby`.

### Lobby (`/lobby`)
- Header: avatar tròn + lời chào + nút đăng xuất.
- 2 card riêng: "Tạo phòng mới" (chọn kịch bản qua `<select>`, nút `.btn-primary`) và "Vào phòng có sẵn" (nhập mã + nút `.btn-accent`).
- Tạo phòng → chọn kịch bản → vào `/room/{room_code}`.
- Nhập mã phòng → join nếu phòng tồn tại và đang chờ.

### Room — phòng chờ (`/room/{room_code}`)

Bố cục thực tế là 2 `.glass-card` xếp dọc (không phải 2 cột như bản thiết kế đầu — mobile-first, đơn giản hơn để dễ đọc trên điện thoại):

```
┌──────────────────────────────────────────┐
│  Mã phòng: ABC123          [Sao chép]    │  ← .glass-card #1
│  ● Ghế 1 - A 👑        [✓ Sẵn sàng]      │
│  ● Ghế 2 - B           [  Chờ...  ]      │
│  ● Ghế 3 - C           [✓ Sẵn sàng]      │
│  [Hủy sẵn sàng]         [Bắt đầu] (Host) │
│  [        Thoát phòng        ]           │
│              Sẵn sàng: 2/3               │
├──────────────────────────────────────────┤
│  Tùy chọn ván đấu (Host only chỉnh được) │  ← .glass-card #2
│  ☐ Lộ role khi chết                      │
│  Thời gian thảo luận (giây):  [300]      │  ← number input, không phải slider
│  Cho vote sớm sau (giây):     [180]      │
│  Thời gian bỏ phiếu (giây):   [ 60]      │
│  Thời gian ban đêm (giây):    [ 60]      │
│  [       Lưu tùy chọn       ]            │
└──────────────────────────────────────────┘
```

Khác biệt so với thiết kế gốc:
- Nút **Sẵn sàng** là toggle (đổi thành "Hủy sẵn sàng" khi đã bấm), không phải nút cố định.
- Có thêm nút **Thoát phòng** (viền đỏ, `.btn-danger-outline`) — gửi `LEAVE_ROOM`, xoá ghế, tự chuyển host nếu cần, quay về `/lobby`.
- Panel tùy chọn dùng **ô nhập số** (`type="number"`, có `min`/`max`/`step`, clamp khi blur) thay vì slider — dễ nhập chính xác hơn trên cả desktop lẫn mobile.
- Không có mục "Chỉnh sửa role" hay "Số người" riêng — số người tự động theo số ghế đã join, danh sách role tự tính theo `ScenarioFiller` ở backend.

Nút Bắt đầu active khi: tất cả đã nhấn Sẵn sàng **và** số người ≥ `min_players` của kịch bản.

### Game screen (`/game/{room_code}`)

**Desktop:** 2 cột giống thiết kế gốc — seat circle bên trái, chat panel bên phải, thanh trạng thái cố định dưới cùng.

```
┌──────────────────────────┬───────────────────────┐
│   Seat circle             │   Chat panel (.glass-card) │
│   (CSS, absolute + trig) │                        │
│                          │   [System banners]     │
│   Người chết:            │   [Chat bubbles]       │
│   opacity-40 grayscale   │   ── 💀 Người chết ──  │

│   [Night action panel]   │   ───────────────────  │
```

Role reveal đầu ván hiện dưới dạng overlay toàn màn hình (nền đen mờ `rgba(0,0,0,0.6)`) chứa `RoleCard` (`.glass-card`) + nút "Đã rõ".

## 4. Chat panel

### Feed duy nhất

Một feed cuộn gộp tất cả, y hệt thiết kế gốc:
- **Chat bubble** — lời nói người chơi (ban ngày). Bubble của mình căn phải.
- **System banner** — sự kiện hệ thống (phase đổi, người chết, kết quả vote), màu theo `kind` (`death`/`reveal`/`warn`/`phase`/`info`/`safe`/`end`).
- **Dead chat divider + messages** — chỉ render cho người đã chết.
- **Live vote counter** — cập nhật in-place trong phase vote (component `VoteCounter`, không tạo dòng mới mỗi lần update).

### Kênh người chết

Giống thiết kế gốc:
- FE chỉ render phần dưới divider `── 💀 Chỉ người chết thấy ──` nếu `isAlive === false`.
- Người sống không thấy divider và kênh bên dưới.
- Ghost (Hồn Ma): giới hạn 1 từ/ngày ở chat chung — FE chặn submit nếu `text.split(/\s+/).length > 1` hoặc đã dùng lượt trong round hiện tại.

### Live vote counter

```
⚖️ Đang bỏ phiếu... (7/9 đã vote)
   Ghế 3   ████████░░  4
   Ghế 5   ████░░░░░░  2
```

Thanh tiến trình dùng gradient đỏ→cam (`linear-gradient(90deg, var(--accent-red), var(--accent-orange))`), không hiển thị ai bỏ cho ai — chỉ tổng số phiếu mỗi mục tiêu, đúng thiết kế gốc.

## 5. Mention highlight

Xử lý hoàn toàn client-side trong `hooks/useMentionHighlight.js`, logic giữ nguyên như thiết kế gốc (regex lookbehind/lookahead cho số ghế + tên hiển thị). Khi `isMentioned === true`: bubble có viền `--accent-orange` 2px + class `.mention-pulse` (animation box-shadow lan toả màu cam, không phải viền vàng `--color-9` như bản màu cũ).

*Chưa làm:* âm thanh "ting" khi được nhắc tới — hiện chỉ có hiệu ứng viền, chưa có audio.

## 6. Timer — 2 chế độ

Giữ nguyên logic thiết kế gốc: đồng hồ đếm ngược `MM:SS` hoặc progress bar, chọn qua click vào chính timer, lưu `localStorage`, sync với server time từ `PHASE_CHANGE` (`duration_seconds` + `started_at`), không dùng client clock riêng.

Màu progress bar theo % còn lại: >50% → `--accent-orange`, 20-50% → `--warning`, <20% → `--danger` (thay vì xanh→vàng→đỏ của bản palette cũ).

## 7. Animation (Framer Motion)

Giữ nguyên 3 animation của thiết kế gốc — reveal role (card flip), người chết (fade + grayscale + scale), phase transition đêm (overlay tối dần) — chỉ đổi màu overlay đêm từ đen thuần sang gradient tối `#0d1420 → #030407` để nhất quán với nền sao của toàn app thay vì cắt ngang bằng nền đen phẳng.

---

## 8. State management (Zustand)

Giữ nguyên kiến trúc thiết kế gốc, không đổi:

**`gameStore.js`** — toàn bộ game state, cập nhật theo WebSocket events: `phase`, `round`, `players`, `myRole`, `feed` (chat+banner gộp), `voteCounts`, `roomSettings`, v.v. Có handler riêng cho từng event type (`handlePhaseChange`, `handlePhaseResult`, `handleVoteUpdate`, `handleRoomSettingsUpdate`...).

**`authStore.js`** — user session: `user`, `isAuthenticated`, `login`, `logout`, `register`.

WebSocket event dispatch vào store xảy ra trong `hooks/useWebSocket.js` — một chỗ duy nhất xử lý incoming events, không scatter logic vào từng component.

## 9. Việc còn thiếu so với thiết kế gốc

- Bottom-sheet chat trên mobile (hiện chỉ xếp chồng dọc, không kéo mở/thu nhỏ được).
- Âm thanh "ting" khi mention.
- Cài đặt Settings riêng cho chế độ Timer (hiện đổi bằng cách bấm trực tiếp vào đồng hồ, chưa có màn hình Settings).
- UI đặc thù cho Halfbreed/Grandmother/Red Hood (dùng chung RoleCard mặc định, chưa có hiển thị "biết Sói" riêng cho Red Hood).
- Xử lý sự kiện `RESUME_AVAILABLE` / `GAME_STATE_SYNC` ở FE (BE đã có field liên quan, FE chưa nối).
