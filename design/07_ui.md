## 2. Theme — màu sắc, font, background

Palette định nghĩa một lần trong `frontend/src/config/theme.js`, inject vào `:root` qua `index.css`. Không hardcode màu trong component — chỉ dùng CSS variable.

```css
:root {
  --color-1:  #11516f;  /* deep teal    — header, border */
  --color-2:  #267e96;  /* mid teal     — primary button */
  --color-3:  #369daf;  /* teal accent  — link, active state */
  --color-4:  #64b5bf;  /* light teal   — secondary element */
  --color-5:  #a6bbbb;  /* gray-teal    — divider, disabled */
  --color-6:  #e68d81;  /* coral        — death / danger */
  --color-7:  #f2b8a0;  /* peach        — warning / vote */
  --color-8:  #f5cb9c;  /* light peach  — highlight banner */
  --color-9:  #fbd384;  /* gold         — night accent, mention */
  --color-10: #f3d8bb;  /* cream        — card bg, chat bubble */
}
```

**Mapping:**
- Người chết trên seat circle: `opacity-40 grayscale` (Tailwind utility).
- Banner chết/trục xuất: nền `--color-6`, chữ trắng.
- Banner sự kiện thường: nền `--color-8`.
- Phase đêm: overlay `--color-1` opacity 60%, accent `--color-9`.
- Chat bubble người sống: nền `--color-10`.
- Mention highlight: viền `--color-9`, nền đậm hơn `--color-10`.
- Tên Sói (chỉ Sói thấy): chữ `--color-6`, nền `--color-1`.

**Font:** `"Times New Roman", Times, serif` — set một lần trên `body`.

**Background:** 1 ảnh cố định ở `<body>` (`background-attachment: fixed`, `background-size: cover`). URL là config value trong `theme.js`. Fallback nếu ảnh lỗi: gradient chéo `--color-1` → `--color-9`.

## 4. Chat panel

### Feed duy nhất

Một feed cuộn gộp tất cả:
- **Chat bubble** — lời nói người chơi (ban ngày).
- **System banner** — sự kiện hệ thống (phase đổi, người chết, kết quả vote).
- **Dead chat divider + messages** — chỉ render cho người đã chết.
- **Live vote counter** — cập nhật in-place trong phase vote.

### Kênh người chết

Cùng cửa sổ chat, phân tách bằng divider `── 💀 Chỉ người chết thấy ──`:
- FE chỉ render phần dưới divider nếu `currentUser.is_alive === false`.
- Người sống không thấy divider và kênh bên dưới.
- Ban đêm: kênh người chết **vẫn mở**. Chat chung bị khóa với người sống.
- Ghost (Hồn Ma): được gửi 1 từ/ngày vào chat chung — FE đếm số lần đã dùng và disable input sau khi đủ 1 từ.

### Live vote counter

Trong phase vote, hiển thị in-place (không tạo dòng mới mỗi lần update):

```
⚖️ Đang bỏ phiếu... (7/9 đã vote)
   Ghế 3: ████░░  4 phiếu
   Ghế 5: ██░░░░  2 phiếu
   Trắng: █░░░░░  1 phiếu
```

Không hiển thị ai bỏ cho ai cho đến khi phase kết thúc — chỉ hiện tổng số phiếu mỗi mục tiêu.

## 5. Mention highlight

Xử lý **hoàn toàn client-side** trong `hooks/useMentionHighlight.js`. Không cần backend.

```javascript
const useMentionHighlight = (message, mySeatNumber, myDisplayName) => {
  const patterns = [
    new RegExp(`(?<!\\d)${mySeatNumber}(?!\\d)`, 'g'),
    new RegExp(`#${mySeatNumber}(?!\\d)`, 'g'),
    new RegExp(`\\b${escapeRegex(myDisplayName)}\\b`, 'gi'),
  ];
  return patterns.some(p => p.test(message));
};

const escapeRegex = (str) => str.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
```

Pattern số dùng lookbehind + lookahead để tránh nhầm: "3" match nhưng "13", "30", "133" không match.

Khi `isMentioned === true`:
- Bubble render với viền `--color-9` + nền đậm hơn.
- Phát âm thanh "ting" nhỏ (nếu chưa tắt âm).
- Người khác thấy bubble bình thường.

## 6. Timer — 2 chế độ

Người chơi tự chọn trong Settings, lưu vào `localStorage`:

| Chế độ | Mô tả |
|---|---|
| Thanh tiến trình | Progress bar, màu chuyển xanh → vàng → đỏ theo % còn lại |
| Đồng hồ | Số đếm ngược `MM:SS`, font lớn |

Cả hai sync với server time từ event `PHASE_CHANGE` (`duration_seconds` + `started_at`), không dùng client clock để tránh lệch giữa các thiết bị:

```javascript
// hooks/useGameTimer.js
const useGameTimer = (durationSeconds, serverStartedAt) => {
  const elapsed = (Date.now() - new Date(serverStartedAt)) / 1000;
  const remaining = Math.max(0, durationSeconds - elapsed);
  // setInterval mỗi giây để re-render
  return remaining;
};
```

## 7. Animation (Framer Motion)

### Reveal role đầu ván
Card flip animation khi người chơi nhận role:
```jsx
<motion.div
  initial={{ rotateY: 180, opacity: 0 }}
  animate={{ rotateY: 0, opacity: 1 }}
  transition={{ duration: 0.6, ease: "easeOut" }}
>
  <RoleCard role={myRole} />
</motion.div>
```

### Người chết
Ghế fade + desaturate khi người chơi chết:
```jsx
<motion.div
  animate={isAlive ? {} : { opacity: 0.4, filter: "grayscale(100%)", scale: 0.95 }}
  transition={{ duration: 0.8 }}
>
  <SeatAvatar player={player} />
</motion.div>
```

### Phase transition đêm/ngày
Overlay tối dần toàn màn hình khi vào đêm:
```jsx
<AnimatePresence>
  {phase === 'night' && (
    <motion.div
      className="fixed inset-0 bg-black pointer-events-none"
      initial={{ opacity: 0 }}
      animate={{ opacity: 0.6 }}
      exit={{ opacity: 0 }}
      transition={{ duration: 1.2 }}
    />
  )}
</AnimatePresence>
```

## 8. State management (Zustand)

Hai store chính:

**`gameStore.js`** — toàn bộ game state, cập nhật theo WebSocket events:
- `phase`, `round`, `players`, `myRole`, `chatMessages`, `voteCount`, `timeRemaining`
- Handler cho từng event type: `handlePhaseChange`, `handlePlayerDead`, `handleVoteUpdate`, v.v.

**`authStore.js`** — user session:
- `user` (từ JWT cookie), `isAuthenticated`
- `login`, `logout`

WebSocket event dispatch vào store xảy ra trong `hooks/useWebSocket.js` — một chỗ duy nhất xử lý incoming events, không scatter logic vào từng component.
